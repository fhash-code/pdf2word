PDF2Word - PDF to Word Converter

**Convert PDF files to Word documents while preserving the original layout, tables, and fonts.**
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Windows](https://img.shields.io/badge/Platform-Windows-0078d7.svg)](https://www.microsoft.com/windows)
![GitHub Releases](https://img.shields.io/github/downloads/fhash-code/pdf2word/total)

A modern, offline, and free tool to convert your PDF files into editable Word documents without sending your data to any server.

✨ Features

- **Preserves Original Layout**: Keeps fonts, tables, images, and formatting intact.
- **100% Offline & Private**: Your files never leave your computer. No internet connection required.
- **Microsoft Word Engine**: Uses Microsoft Word for the highest quality conversion.
- **Multi-language Support**: Available in **English**, **Persian (فارسی)**, **Arabic**, **Chinese**, and **Russian**.
- **Intuitive Interface**: Simple drag-and-drop or browse to select files.
- **Donation Support**: Includes a QR code for cryptocurrency donations (BEP-20, TRC20).


 💻 System Requirements

- **Operating System**: Windows 10 or 11
- **Software**: Microsoft Word 2010 or later (must be installed)
- **Hard Disk Space**: ~50 MB for the application itself

 🚀 Installation

Getting started is very easy.

1.  **Go to the [Releases](https://github.com/fhash-code/pdf2word/releases) page.**
2.  Download the latest `PDF2Word.exe` file.
3.  **That's it!** You can run the program immediately. No installation is required.

 🛠️ Usage

1.  Click **"Browse"** to select your PDF file.
2.  (Optional) Enter a custom name for the output Word file.
3.  Choose the folder where you want to save the result.
4.  Click **"Convert to Word"**.
5.  The converted file will open automatically once the process is finished.
